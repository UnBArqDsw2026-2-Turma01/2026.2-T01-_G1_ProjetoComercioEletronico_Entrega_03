# Rastreabilidade do Cumprimento da Metodologia

## 1. Objetivo

Este documento tem como finalidade evidenciar, de forma rastreável, que os elementos da metodologia Scrum adaptada (descrita em [`Metodologia.md`](/Base/Relatórios/Subequipe03/Metodologia.md)) foram efetivamente seguidos ao longo das duas Sprints do projeto. Cada elemento planejado é associado a uma evidência concreta de execução (ata, artefato, commit, print ou link), permitindo auditar o processo do início ao fim.

> **Como preencher:** para cada linha da tabela, adicione a data em que o evento ocorreu e um link/referência para a evidência (ata de reunião, commit no Git, print de conversa do grupo, arquivo do diagrama, etc.). Itens sem evidência disponível devem ser marcados como "Pendente" e justificados na seção de observações.
